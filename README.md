# Монополия — терминал

Сайт для настольной Монополии: два 3D-кубика, переводы между игроками, режим банка, калькулятор и история операций. Работает с телефона (iPhone 8 / 13), баланс синхронизируется между всеми телефонами в реальном времени.

## Запуск на компьютере

1. Нужен Node.js 18 или новее.
2. Дважды кликните `start.bat` (или выполните `npm install` и `npm start`).
3. Откройте `http://localhost:3000`. Адрес для телефона (в той же Wi-Fi сети) сервер выведет в консоли.

## Как играть

1. Один игрок нажимает «Создать комнату» и задаёт стартовые деньги и сумму за круг.
2. Остальные вводят имя и 4-значный код. Код и ссылка есть в ⚙️ → «Поделиться».
3. Вкладки: 🎲 кубики (тап по экрану), 💸 терминал, 🧮 калькулятор, 📜 история.
4. Тот, кто **создал комнату**, становится банкиром: только у него вверху есть переключатель **Игрок / Банк**. У остальных игроков его нет, и сервер не даст им выдавать или забирать деньги.
   - **Игрок**: выбираете получателя (игрок или Банк), вводите сумму, «Перевести».
   - **Банк** (только создатель): выбираете игрока, «Выдать» или «Забрать». Есть кнопка «Старт». В ⚙️ можно удалить игрока или начать заново.
   - **Закрыть комнату** (⚙️ → «Закрыть комнату для всех…», только у создателя): комната удаляется у всех, телефоны возвращаются на экран входа.
5. В калькуляторе кнопка «→ Подставить в терминал» переносит результат в поле суммы.

## Вход, PIN и защита от подделки

- У каждого игрока есть **секретный ключ**, который сервер выдаёт только ему и хранит на его телефоне. Идентификаторы игроков видят все, но одного идентификатора для входа мало.
- У каждого игрока есть личный **PIN из 4 цифр** (⚙️ меню → «Ваш PIN»). Он нужен, чтобы вернуться в игру на другом телефоне или после очистки браузера: введите тот же код комнаты, то же имя, и появится поле PIN. Пять неверных PIN подряд блокируют попытки входа в эту комнату на минуту.
- Если банкир (или игрок) потерял вход и забыл PIN, вернуться в свой аккаунт нельзя. Банкир может удалить такого игрока, и тот зайдёт заново со стартовыми деньгами.
- iPhone хранит данные Safari и значка на экране «Домой» отдельно. Поэтому лучше **сначала** добавить сайт на экран «Домой», а уже в нём создавать комнату или входить.

## Установка на iPhone как приложение

Откройте сайт в Safari → «Поделиться» → «На экран “Домой”».

Иконка: скопируйте `app-icon.jpg` из `dice-game-main/public/` в `monopoly-terminal/public/`.

## Хостинг

Нужен хостинг с **Node.js и WebSocket**. Статические хостинги (GitHub Pages, Netlify) не подойдут, так как нужен работающий `server.js`.

- **Render (бесплатно):** залейте проект на GitHub, затем на dashboard.render.com выберите New → Web Service, подключите репозиторий. Build Command: `npm install`, Start Command: `npm start`, Instance Type: Free. Порт Render задаёт сам через `PORT`. Проверочная страница сервера: `/healthz`.
- **Обязательно задайте переменную `BACKUP_SECRET`** (Environment → Add Environment Variable): любая длинная случайная строка, 30 символов и больше. Она нужна для восстановления комнаты (см. ниже). Никому её не показывайте и не выкладывайте на GitHub.
- Подойдут также Railway, Fly.io и подобные.
- Данные хранятся в `data.json`. На бесплатных тарифах файловая система часто стирается при перезапуске. Можно задать переменную `DATA_DIR` на постоянный диск.
- Домашний компьютер можно открыть наружу через Cloudflare Tunnel или ngrok.

## Восстановление комнаты после перезапуска сервера

На бесплатных хостингах сервер засыпает и теряет файлы, а вместе с ними комнаты. Чтобы игра не пропала:

1. Сервер постоянно отправляет **банкиру** (и только ему) свежую копию комнаты: игроки, балансы, история. Копия зашифрована ключом `BACKUP_SECRET`, прочитать или изменить её на телефоне нельзя. Телефон банкира хранит её у себя.
2. Если сервер забыл комнату, банкир при открытии игры отправляет копию обратно вместе со своим секретным ключом. Сервер поднимает комнату с теми же балансами.
3. Остальные игроки видят «Комната не найдена… ждём банкира» и входят сами, как только комната восстановится.

Ограничения:
- Копия свежая настолько, насколько давно банкирский телефон был на связи. Операции, сделанные, пока его телефон был офлайн, при потере комнаты могут не попасть в копию.
- Без `BACKUP_SECRET` восстановление не работает (комнаты на своём компьютере это не затрагивает: они лежат в `data.json`).
- Копия старше 3 дней не принимается. Закрытая банкиром комната не восстанавливается.
- Если вы сменили `BACKUP_SECRET`, старые копии перестанут подходить.
- Если телефон банкира очищен, комнату не восстановить, но остальные игроки могут создать новую.

## Заметки

- Пароля на вход в комнату нет: кто знает адрес сайта и код из 4 цифр, тот может зайти новым игроком (банкиром не станет). Адрес лучше не публиковать.
- Валюта задаётся константой `CURRENCY` в начале `public/app.js`.
