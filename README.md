# Монополия — терминал

Сайт для настольной Монополии: два 3D-кубика, переводы между игроками, режим банка, калькулятор и история операций. Работает с телефона (iPhone 8 / 13), баланс синхронизируется между всеми телефонами в реальном времени.

## Запуск на компьютере

1. Нужен Node.js 18 или новее.
2. Дважды кликните `start.bat` (или выполните `npm install` и `npm start`).
3. Откройте `http://localhost:3000`. Адрес для телефона (в той же Wi-Fi сети) сервер выведет в консоли.

## Как играть

1. Один игрок нажимает «Создать комнату» и задаёт стартовые деньги и сумму за круг.
2. Остальные вводят имя и 4-значный код. Код и ссылка есть в ⚙️ → «Поделиться».
3. Вкладки: 🎲 кубики (тап по экрану), 💸 терминал, 🧮 калькулятор, 📜 история.
4. Тот, кто **создал комнату**, становится банкиром: только у него вверху есть переключатель **Игрок / Банк**. У остальных игроков его нет, и сервер не даст им выдавать или забирать деньги.
   - **Игрок**: выбираете получателя (игрок или Банк), вводите сумму, «Перевести».
   - **Банк** (только создатель): выбираете игрока, «Выдать» или «Забрать». Есть кнопка «Старт». В ⚙️ можно удалить игрока или начать заново.
   - **Закрыть комнату** (⚙️ → «Закрыть комнату для всех…», только у создателя): комната удаляется у всех, телефоны возвращаются на экран входа.
5. В калькуляторе кнопка «→ Подставить в терминал» переносит результат в поле суммы.

## Установка на iPhone как приложение

Откройте сайт в Safari → «Поделиться» → «На экран “Домой”».

Иконка: скопируйте `app-icon.jpg` из `dice-game-main/public/` в `monopoly-terminal/public/`.

## Хостинг

Нужен хостинг с **Node.js и WebSocket**. Статические хостинги (GitHub Pages, Netlify) не подойдут, так как нужен работающий `server.js`.

- **Render (бесплатно):** залейте проект на GitHub, затем на dashboard.render.com выберите New → Web Service, подключите репозиторий. Build Command: `npm install`, Start Command: `npm start`, Instance Type: Free. Порт Render задаёт сам через `PORT`. Проверочная страница сервера: `/healthz`.
- Подойдут также Railway, Fly.io и подобные.
- Данные хранятся в `data.json`. На бесплатных тарифах файловая система часто стирается при перезапуске. Тогда комнаты пропадут, и игру придётся создать заново. Можно задать переменную `DATA_DIR` на постоянный диск.
- Домашний компьютер можно открыть наружу через Cloudflare Tunnel или ngrok.

## Заметки

- Пароля у комнат нет: кто знает адрес сайта и код, тот может зайти (но банкиром не станет).
- Зайти под именем игрока, который сейчас в сети, нельзя. Если банкир потерял сессию (например, добавил сайт на экран «Домой», а там хранилище отдельное), он входит с тем же именем и снова получает банк, когда его старое соединение отключится.
- Валюта задаётся константой `CURRENCY` в начале `public/app.js`.
